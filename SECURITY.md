# Security Policy

## Supported Versions

This repository does not maintain multiple versions or release branches. It contains the source files used to generate the harmonica scores published on the website.

The repository is updated when new scores are added or when issues with existing scores are fixed.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository, please report it privately rather than opening a public issue.

You can use GitHub's **Report a vulnerability** feature, if available for this repository, to submit the issue securely.

For non-security-related issues, please open a regular GitHub issue.
